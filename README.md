## Kegiatan workshop yang didokumentasikan

### Rangkuman Materi
- Prompt Engineering itu penting: Ini adalah cara kita ngasih instruksi ke AI biar hasilnya maksimal. Semakin spesifik dan jelas prompt-nya, semakin bagus output yang dikasih AI. Ini kayak ngasih tahu AI persis apa yang kita mau.
- Git itu sistem yang nyatet semua perubahan yang terjadi pada kode proyek kita.
- GitHub ini platform online tempat kita nyimpen kode proyek yang udah diatur sama Git. Di sini kita bisa kerja bareng tim, lihat perubahan yang dibuat orang lain, dan ngelola proyek bareng-bareng.

### Poin Penting / Pengetahuan Baru
- Jadi tahu kalau AI itu bukan cuma buat bikin sesuatu dari nol, tapi juga bisa bantu banget dalam proses pengembangan software yang pakai Git dan GitHub.
- Paham bedanya Git (sistem kontrol versi lokal) dan GitHub (platform kolaborasi online).

### Pendapat Pribadi tentang Day 1 Proyek Workshop
Menurutku workshop hari ini sangat bermanfaat. Kita juga menjadi tahu bahwa penggunaan AI untuk membuat website dan semacamnya sangat efisien dalam hal waktu. Memang sebaiknya tidak mengandalkan AI, tetapi jika kita bijak dalam cara memanfaatkannya, menurutku aman-aman saja. 
Walaupun agak sedikit lupa saat acaranya selesai, tetapi pas membaca materinya lagi menjadi lebih mengerti, pokoknya hari ini seru.
